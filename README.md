## 📖 项目简介

你好！👋 这是我用 GitHub 创建的第一个仓库。

本项目用于学习和练习 Git 与 GitHub 的基本操作，同时熟悉 Markdown 文档的编写。

---

## 🎯 项目目标

- [x] 学习如何创建 GitHub 仓库
- [x] 学习如何编辑 README 文件
- [ ] 学习如何使用 Git 命令进行本地操作
- [ ] 学习如何将本地代码推送到 GitHub
- [ ] 学习如何拉取（Pull）和同步代码
